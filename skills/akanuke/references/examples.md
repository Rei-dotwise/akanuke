# 直す前と直した後

どれも説明用に作った例で、実在の資料や体験ではない。

各例では、まず元の文にある内容だけで直した版を示す。通常はこちらを使う。書き手から場面や数字を聞けた場合の版は別に示す。聞いていない体験、数字、方針は足さない。

## スライドのキーメッセージ

直す前:

> AI導入の成否を分けるのは、現場の納得感。
> ツールではなく、使い方。
> AIは「代替」ではなく「伴走者」。

元の内容だけで直した後:

> AIの導入がうまくいくかは、現場が納得しているかで決まる
> AIは、使い方しだいで結果が変わる
> AIは人の代わりにせず、人の仕事を助けるものとして使う

3行とも、溜め、体言止め、「〜ではなく〜」の決め台詞だった。直した後は普通の述語で終え、元の主張を変えずに言い切っている。

書き手から手順を聞けた場合は、2行目を「ツールを選ぶ前に、使い方を決める」のように順序まで書ける。方針を聞けた場合は、3行目を「議事録と資料の下書きはAIに任せ、判断と顧客対応は人が行う」のように、業務の名前まで書ける。

次の点を変えた。

- 方針、判断事項、対象範囲の三つを1枚に盛っていたので、共有する1枚と決めてもらう1枚に分けた。
- タイトルを、読めば中身が分かる文にした。2枚目は決めてほしいことを主役にした。
- 「リスク」「ご判断いただきたい点」を3回ずつ繰り返していたので、表の列見出しとして1回だけ置いた。
- 01の番号、縦の仕切り線、左の縦線、ステップ名の下の補足文を外した。順番に意味があるので「1」「2」「3」は残した。
- 3色の塗り分けとミニロードマップを外した。グレーの「活用しない」は、人が行う業務として並べ直した。
- 3行の免責注釈は、資料全体にかかる留保なので、条件を削らずに最終ページへ1回だけ移した。
- 元の「当社案：生産性 約30%向上を目標に設定」は、誰の数字か（当社）、目標か実績か、「約」の幅を変えずに1文にした。
- 「ご判断いただきたい点」は、決める場や期限が元の資料にないので、会議の日程を書き足さずに「ご判断ください」とした。
- 1枚目の結びは、2枚目の未決事項（全社か一部門か）を先取りしないよう、決める場を示すだけにした。
- 「一部 / 門か」の改行は、文を短くして解消した。

## メール

直す前:

```
件名：【ご確認のお願い】【重要】次回お打ち合わせ日程のご調整につきまして

佐藤様

いつも大変お世話になっております。
株式会社サンプルの田中でございます。

先日はお忙しい中、貴重なお時間をいただき、誠にありがとうございました。
御社の課題について深く理解することができ、大変有意義な時間となりました。

さて、本日は次回のお打ち合わせ日程についてご相談させていただきたく、ご連絡させていただきました。

## 候補日程
- **12月1日（火）** 10:00〜11:00
- **12月2日（水）** 14:00〜15:00
- **12月4日（金）** 16:00〜17:00

上記以外でご都合のよろしい日程がございましたら、お気軽にお申し付けください。
ご不明点がございましたら、お気軽にお問い合わせください。

引き続き、何卒よろしくお願い申し上げます。
```

元の内容だけで直した後:

```
件名：次回お打ち合わせ日程のご相談

佐藤様

いつもお世話になっております。株式会社サンプルの田中でございます。
先日はお忙しい中、貴重なお時間をいただき、誠にありがとうございました。

次回のお打ち合わせの日程をご相談させてください。
以下の候補で、ご都合のよい日時はありますでしょうか。

12月1日（火）10:00〜11:00
12月2日（水）14:00〜15:00
12月4日（金）16:00〜17:00

上記以外でご都合のよい日時があれば、お知らせください。
引き続きよろしくお願いいたします。
```

書き手から打ち合わせの中身を聞けた場合:

```
先日はお忙しい中、貴重なお時間をいただき、誠にありがとうございました。
議事録の清書に毎回30分ほどかかっている、というお話は、次回のご提案の前提にさせていただきます。
```

次の点を変えた。

- 件名の【】を二つとも外し、用件だけにした。日程の相談に「重要」を付ける理由が元のメールにない。
- 名乗りとお礼は、社外の相手への普通の定型なので残した。「有意義な時間となりました」は、何が有意義だったのかが書かれていないので削った。中身を聞けた場合は、相手の話のどこを次に使うのかを書く。
- 「さて、本日は〜ご連絡させていただきました」の目的の宣言を、用件の一文にした。「させていただき」が一文に二つ重なっていたので、「ご相談させてください」の一言にした。
- 見出しと太字はメールソフトでは記号のまま見えるので、候補日を1行ずつ並べた。日付と曜日は暦で確かめた。
- 「お気軽に」の二文と締めの重ねを、候補以外の日時を聞く一文と、締めの挨拶一つにまとめた。候補以外の日でもよい、という元の条件は変えていない。

## トークスクリプト

直す前:

```
【導入】
本日はお忙しい中、貴重なお時間をいただき、誠にありがとうございます。
本日は、貴社の営業活動における課題を整理し、生成AIを活用した業務効率化の可能性についてご提案させていただきます。

【課題の確認】
多くの営業組織では、議事録作成や提案資料の準備といった付帯業務に多くの時間を要しており、本来注力すべき顧客との対話に十分な時間を割けていないという課題が存在します。
貴社においても、同様の課題をお持ちではないでしょうか。
お客様：「まさにその通りです」

【切り返し】
おっしゃる通りです。そのお気持ち、大変よく分かります。
実は、同様の課題をお持ちだった企業様でも、導入後に劇的な変化が生まれています。
```

元の内容だけで直した後:

```
導入
本日はお忙しい中、貴重なお時間をいただき、誠にありがとうございます。
まず、御社の営業の課題を整理します。
そのうえで、生成AIを使って業務の手間を減らせるか、その見込みをご提案します。

課題の確認
議事録や提案資料の準備などに時間を取られて、取引先と話す時間が足りない、ということはありますか。
（ここで答えを待つ）

「ある」と言われたら
同じ課題をお持ちだった会社では、導入のあとに変わったところがあります。

「特にない」と言われたら
（要確認：この場合に次に話すことを書き手に聞く）
```

書き手から事例を聞けた場合:

```
「ある」と言われたら
同じように議事録に時間がかかっていた会社では、1件30分ほどだった清書が、10分ほどになりました。
```

次の点を変えた。

- 70字を超える一文を、一つの文に一つのことが入る長さに切った。「貴社」「〜において」「付帯業務」は、話すときの言い方に直した。冒頭のお礼は商談の定型なので残した。
- 「効率化の可能性についてご提案」は、方法を約束する言い方にせず、「減らせるか、その見込み」として可能性の範囲にとどめた。
- 「多くの営業組織では」は出典がないので、相手に直接聞く問いの中身にした。元の問い（同様の課題をお持ちか）の範囲は変えていない。はい・いいえで答える問いのままなので、事実を聞く問い（「議事録に今どのくらい時間をかけていますか」）にするかは、書き手に確かめてから変える。
- 相手のせりふ「まさにその通りです」を消した。相手がそう答えるとは限らないので、答えごとに次に話すことを分けた。元の台本にない側（課題がない場合）は、作らずに要確認とした。
- 「おっしゃる通りです」「大変よく分かります」は、相手が課題を認めただけの場面には合わないので外した。
- 「劇的な変化」は根拠がないので、変化があったという元の主張だけを残した。何が変わったのかは、事例を書き手から聞けた場合だけ書く。

## 直しすぎた例

社内チャットでの共有を、AIっぽさを抜こうとして、別の型に入れてしまった例を挙げる。

> 正直、議事録AIってまだ微妙なんですよね（笑）。でも、使い方次第でめっちゃ変わるんです！ぶっちゃけ、自分も最初は全然ダメダメでした。

「正直」「ぶっちゃけ」「（笑）」「めっちゃ」を足して、くだけた感じを演出している。最後の失敗談も、書き手から聞いていなければ作り話になる。直すなら、元の文にある内容（議事録AIはまだ微妙だが、使い方で変わる）を普通の口調で書く。

> 議事録AIはまだ使いにくいところがありますが、使い方で結果が変わります。

どこが使いにくいのかを書き手から聞けた場合は、「文字起こしはそのまま使えますが、要約はまだ人の確認が要ります」のように具体的に書ける。
